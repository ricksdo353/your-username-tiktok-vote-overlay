# LucidOrbBot – בוט למבחן LucidFlex 50K

בוט ל-NinjaTrader 8 שסוחר בפריצת טווח הפתיחה (Opening Range Breakout) על MNQ/NQ. חוקי Lucid מובנים בקוד.

## קבצים
| קובץ | מה זה |
|---|---|
| `LucidOrbBot.cs` | הבוט (NinjaScript) |
| `simulate_lucid.py` | סימולטור שמחשב סיכויי מעבר ומשיכה לפי חוקי Lucid |

## האסטרטגיה
1. בונה טווח מהדקה 9:30 עד 9:45 (שעון ניו יורק).
2. נכנס כשנר דקה נסגר מעל הטווח (לונג) או מתחתיו (שורט), עד 11:30.
3. הסטופ שווה לגודל הטווח, בין 15 ל-60 נקודות. היעד שווה לסטופ כפול יחס הרווח לסיכון.
4. גודל הפוזיציה מחושב לפי הסכום בדולרים שמוכנים לסכן בעסקה.
5. סוגר הכול ב-15:50.

## הגנות שמובנות בקוד
- **תקרת רווח יומית:** שומרת על חוק העקביות של 40%.
- **עצירת הפסד יומית.**
- **מקסימום עסקאות ביום:** 1–2, רחוק מהגבולות של HFT.
- **מרחק מקו ה-drawdown:** הבוט לא יסכן יותר מהמרחק שנשאר מהרצפה.
- **עצירה ביעד:** מפסיק לסחור ברגע שהגיע ל-3,000$.

## שני מצבים
| מצב | איך זה עובד | למי |
|---|---|---|
| **Sprint** | עסקה אחת ביום. מסכן כ-1,900$ כדי להרוויח כ-1,050$. צריך DLL כבוי בחשבון | הסיכוי הכי גבוה לעבור תוך 3 ימים, אבל הפסד אחד שורף את החשבון |
| **Steady** | עד 2 עסקאות ביום, סיכון 250$, יחס 1:2 | הסיכוי הכי גבוה לעבור **וגם** למשוך כסף |

## התקנה
1. העתק את `LucidOrbBot.cs` לתיקייה `Documents\NinjaTrader 8\bin\Custom\Strategies\`.
2. ב-NinjaTrader פתח New → NinjaScript Editor ולחץ F5 כדי לקמפל.
3. שנה את אזור הזמן ל-Eastern: Tools → Options → General → Time zone.
4. **קודם כול backtest:** פתח את Strategy Analyzer, בחר MNQ 1 Minute ותקופה של שנתיים לפחות.
5. שבוע בחשבון Sim, ורק אחר כך בחשבון המבחן.
6. כל בוקר עדכן את `Profit so far` ואת `Drawdown floor` לפי מה שמופיע בלוח הבקרה של Lucid.

## חישוב סיכויים לפי ה-backtest שלך
אחרי ה-backtest קח את אחוז ההצלחה ואת היחס בין הרווח הממוצע להפסד הממוצע, והרץ:
```
python3 simulate_lucid.py --winrate 0.45 --rr 1.6 --risk 250
```
